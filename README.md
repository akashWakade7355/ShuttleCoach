# ShuttleCoach - AeroCourt Mobile

This is the mobile frontend for **ShuttleCoach / AeroCourt**, an AI-powered badminton shadow footwork and training analytics platform built with React Native and Expo.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npx expo start
   ```

You can open the app in iOS Simulator, Android Emulator, Expo Go, or Web browser.
